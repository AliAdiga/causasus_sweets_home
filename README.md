# Caucasus Sweets Home

Static website (Arabic / English) for دار الحلويات القوقازية, Amman.
Plain HTML, CSS and JavaScript, so there is nothing to build: open `index.html` or deploy the folder as is.

- `index.html` home page, `products.html` menu and prices
- `products-data.js` menu items and prices, `i18n.js` English translations
